# Assets Originais

Origem: prototipo publico fornecido pelo usuario, arquivo Ff0SksUi7UFtPWUO8kyNtw,
frame 2-2, consultado em 3 de outubro de 2026.

Os quatro PNGs foram obtidos das respostas de imagem que o proprio prototipo
carrega de `s3-alpha-sig.figma.com`, sem gerar ou reconstruir os retratos.
Evidencias de composicao: `reports/figma-prototype.png` e `reports/figma-lower.png`.

`npm run assets:export` gera as copias de distribuicao WebP em `public/artworks/`,
768 px e qualidade 88, preservando proporcoes, sem crop ou alteracao de conteudo.
Os PNGs originais permanecem aqui. As URLs publicas sao estaveis entre builds.
IDs, nomes, precos e estoque dos NFTs continuam sendo dados simulados da API.
